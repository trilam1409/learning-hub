## Điều kiện và toán tử

Python có toán tử số học `+`, `-`, `*`, `/`; so sánh `>=`, `==`, `!=`; logic `and`, `or`, `not`. Sử dụng dấu ngoặc để thể hiện rõ ý định khi kết hợp điều kiện.

```python
price = 12000
horsepower = 130
if price < 15000 and horsepower >= 120:
    print("Xe phù hợp tiêu chí")
else:
    print("Cần kiểm tra thêm")
```

## Vòng lặp và list comprehension

```python
prices = [8000, 12000, 22000, 15000]
cheap = [price for price in prices if price < 15000]
print(cheap)  # [8000, 12000]
```

Một `for` xử lý từng phần tử; `while` lặp khi điều kiện còn đúng; `break` dừng vòng lặp và `continue` bỏ qua lượt hiện tại.

## Hàm tái sử dụng

```python
def average(values):
    return sum(values) / len(values)

print(average([4, 6, 8]))  # 6.0
```

Slide thực hành Python còn giới thiệu `lambda`, đối số mặc định, `*args`, `**kwargs`. Bạn nên thực hành trên các ví dụ nhỏ trước khi đưa vào Pandas.
