# Chuẩn hóa Min-Max

**Đã học trong Buổi 04.** Bài này được biên tập từ slide *Bài 02 – Sắp xếp dữ liệu* và transcript của buổi học. Các ví dụ số bên dưới được biên soạn để luyện tập, không phải dữ liệu gốc do thầy cung cấp.

## Tại sao cần chuẩn hóa dữ liệu?

Các cột trong một bảng có thể có thang đo rất khác nhau: chiều dài xe tính bằng đơn vị nhỏ, giá xe lại có thể lên đến hàng chục nghìn. Khi phân tích hoặc áp dụng một số thuật toán máy học, thang đo chênh lệch có thể khiến một thuộc tính chi phối kết quả.

**Min-Max scaling** đưa một cột dữ liệu về khoảng từ 0 đến 1 (khi dùng thiết lập mặc định và áp dụng lên dữ liệu nằm trong phạm vi đã dùng để tính min/max).

## Công thức

`x_new = (x - x_min) / (x_max - x_min)`

Trong đó:

- `x`: giá trị gốc cần chuyển đổi.
- `x_min`: giá trị nhỏ nhất của cột.
- `x_max`: giá trị lớn nhất của cột.
- `x_new`: giá trị sau khi chuẩn hóa.

Ví dụ có dãy `[20, 40, 60, 80, 100]`. Với `x = 60`, ta tính:

`(60 - 20) / (100 - 20) = 0.5`

| Giá trị gốc | Sau Min-Max |
| ---: | ---: |
| 20 | 0 |
| 40 | 0.25 |
| 60 | 0.5 |
| 80 | 0.75 |
| 100 | 1 |

Nếu tất cả giá trị trong cột đều bằng nhau, mẫu số bằng 0; cần xử lý trường hợp này thay vì chia trực tiếp.

## Thực hành với Pandas

```python
import pandas as pd

values = pd.Series([20, 40, 60, 80, 100], name="value")
min_value = values.min()
max_value = values.max()

scaled = (values - min_value) / (max_value - min_value)
print(scaled)
```

Pandas thực hiện phép toán cho toàn bộ Series, không cần tự viết vòng lặp qua từng phần tử.

## Thực hành với Scikit-learn

```python
import pandas as pd
from sklearn.preprocessing import MinMaxScaler

df = pd.DataFrame({"value": [20, 40, 60, 80, 100]})
scaler = MinMaxScaler()
df["value_scaled"] = scaler.fit_transform(df[["value"]])
print(df)
```

Trong quy trình machine learning, hãy **fit scaler chỉ trên tập training**, sau đó dùng `transform` với tập validation hoặc test để tránh rò rỉ dữ liệu.
