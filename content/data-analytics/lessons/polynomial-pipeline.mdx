## Khi đường thẳng chưa phù hợp

Polynomial regression cho phép mô hình biểu diễn những mối quan hệ cong. Ví dụ bậc hai:

<MathFormula latex={String.raw`\hat{y} = b_0 + b_1x + b_2x^2`} />

Với nhiều biến, có thể thêm tích `x1*x2`, bình phương các biến... Nhưng khi bậc tăng, số đặc trưng có thể tăng rất nhanh và dễ overfitting.

## PolynomialFeatures

```python
import numpy as np
from sklearn.preprocessing import PolynomialFeatures
from sklearn.linear_model import LinearRegression

X = np.array([[1], [2], [3], [4]], dtype=float)
y = np.array([2, 5, 10, 17], dtype=float)
poly = PolynomialFeatures(degree=2, include_bias=False)
X_poly = poly.fit_transform(X)
model = LinearRegression().fit(X_poly, y)
print(model.predict(poly.transform([[5]])))
```

## Pipeline giải quyết điều gì?

Slide Bài 06 mô tả chuỗi **chuẩn hóa → tạo biến đa thức → hồi quy**.

```python
from sklearn.pipeline import Pipeline
from sklearn.preprocessing import StandardScaler, PolynomialFeatures
from sklearn.linear_model import LinearRegression

pipeline = Pipeline([
    ("scale", StandardScaler()),
    ("poly", PolynomialFeatures(degree=2, include_bias=False)),
    ("regression", LinearRegression()),
])
pipeline.fit(X, y)
print(pipeline.predict([[5]]))
```

Pipeline giúp đóng gói trình tự biến đổi, giảm lỗi khi áp dụng lên dữ liệu mới. Khi chia train/test hoặc cross-validation, bước `fit` của scaler cần diễn ra **chỉ trong dữ liệu train** để tránh data leakage.
