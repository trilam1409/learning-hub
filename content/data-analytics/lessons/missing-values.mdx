## Dữ liệu khuyết là gì?

Slide Bài 02 liệt kê nhiều cách dữ liệu thô thể hiện giá trị thiếu: `?`, `NA`, `NaN`, `Null`, ô trống, đôi khi cả số 0 tùy ngữ cảnh. **Không được tự động coi mọi số 0 là thiếu**.

## Thay ký hiệu thiếu

```python
import pandas as pd
import numpy as np

df = pd.DataFrame({
    "price": ["10000", "?", "12000"],
    "horsepower": [100, None, 120],
})
df = df.replace("?", np.nan)
df["price"] = pd.to_numeric(df["price"], errors="coerce")
print(df.isna().sum())
```

## Hai lựa chọn phổ biến

- **Xóa** dòng hoặc cột: `dropna()`, phù hợp khi không thể sử dụng quan sát thiếu và số mẫu bị mất chấp nhận được.
- **Điền** giá trị: `fillna()`, có thể dùng trung bình, trung vị hoặc giá trị theo nhóm khi có lý do hợp lý.

```python
median_hp = df["horsepower"].median()
df["horsepower"] = df["horsepower"].fillna(median_hp)
df = df.dropna(subset=["price"])
```

Giảng viên có trao đổi về điền khuyết và loại bỏ giá trị thiếu trong Buổi 04. Không có một phương pháp đúng cho mọi cột; hãy giải thích vì sao chọn phương pháp đó.
