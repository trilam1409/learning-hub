## Vẽ trực tiếp bằng Pandas

Pandas hỗ trợ phương thức `plot()` cho Series và DataFrame. Bên dưới nó thường sử dụng backend Matplotlib, nên có thể phối hợp với `pyplot`.

```python
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "year": [2021, 2022, 2023, 2024],
    "cars": [120, 180, 160, 220],
})
df.plot(x="year", y="cars", kind="line", marker="o")
plt.title("Số xe theo năm")
plt.show()
```

## Chọn kind

| kind | Ý nghĩa |
| --- | --- |
| `line` | Đường, mặc định |
| `bar`, `barh` | Cột đứng, cột ngang |
| `hist` | Phân bố tần suất |
| `box` | Biểu đồ hộp |
| `area` | Biểu đồ vùng |
| `scatter` | Đám mây điểm; sử dụng trên DataFrame |

## Hai cột số và biểu đồ

```python
df = pd.DataFrame({"x": [1, 2, 3], "y": [2, 4, 7]})
df.plot(x="x", y="y", kind="scatter")
plt.show()
```
