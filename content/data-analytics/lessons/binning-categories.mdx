## Khi nào nên chia khoảng?

Đôi khi cần diễn giải dữ liệu liên tục bằng nhóm dễ hiểu, chẳng hạn điểm thấp/vừa/cao hay phân khúc giá. Slide Bài 02 giới thiệu cách tìm cận và chia thành bins.

```python
import pandas as pd

df = pd.DataFrame({"price": [8000, 12000, 18000, 25000]})
df["price_band"] = pd.cut(
    df["price"],
    bins=[0, 10000, 20000, 30000],
    labels=["Thấp", "Trung bình", "Cao"],
    include_lowest=True
)
print(df)
```

## Điểm cần hiểu

- `bins` là ranh giới của các khoảng.
- Số nhãn bằng **số khoảng**, tức số mốc trừ một.
- `right=True` mặc định tạo khoảng đóng bên phải.
- Giá trị nằm ngoài các mốc được gán thiếu nếu không mở rộng phạm vi.
