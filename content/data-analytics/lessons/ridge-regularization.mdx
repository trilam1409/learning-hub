## Mục tiêu học

- Giải thích tác động của alpha tới hệ số hồi quy Ridge.
- Nhận diện nhu cầu chuẩn hóa khi đặc trưng có đơn vị khác nhau.

## Ridge giải quyết vấn đề gì?

Ridge Regression mở rộng hồi quy tuyến tính bằng **L2 regularization**, thêm hình phạt đối với bình phương độ lớn các hệ số (không phạt intercept trong triển khai sklearn mặc định).

<MathFormula latex={String.raw`\min_{b_0,\mathbf{b}}\ \sum_i (y_i - \hat{y}_i)^2 + \alpha \sum_j b_j^2`} />

- `alpha = 0`: gần với hồi quy bình phương tối thiểu thông thường.
- `alpha` lớn: phạt hệ số mạnh hơn, có thể giảm overfitting nhưng quá lớn dẫn đến underfitting.
- Không có alpha tối ưu chung; cần chọn qua kiểm chứng trên dữ liệu.

## Thực hành

```python
import numpy as np
from sklearn.preprocessing import StandardScaler
from sklearn.linear_model import Ridge
from sklearn.pipeline import make_pipeline

X = np.array([[2, 10], [3, 13], [4, 17], [5, 20], [6, 22]], dtype=float)
y = np.array([12, 15, 18, 20, 24], dtype=float)

for alpha in [0.01, 0.1, 1, 10]:
    model = make_pipeline(StandardScaler(), Ridge(alpha=alpha)).fit(X, y)
    print(alpha, model.predict([[4.5, 18]])[0])
```

**Vì sao chuẩn hóa?** L2 penalty phụ thuộc độ lớn hệ số, nên nếu các đặc trưng khác thang đo, mức phạt có thể bị lệch không mong muốn.

## Tóm tắt

Ridge thêm mức phạt theo bình phương độ lớn của các hệ số. Alpha điều chỉnh mức phạt.

## Điểm dễ nhầm

Alpha quá lớn có thể làm mô hình thiếu khớp. Giá trị phù hợp nên được chọn bằng validation.
