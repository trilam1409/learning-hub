## Z-score là gì?

Z-score biểu diễn một giá trị nằm cách trung bình bao nhiêu độ lệch chuẩn. Trong slide Bài 02, công thức là:

<MathFormula latex={String.raw`z = \frac{x - \mu}{\sigma}`} />

- `x` là giá trị đang xét.
- `μ` là trung bình của cột.
- `σ` là độ lệch chuẩn.

Z-score **không giới hạn trong [0, 1]**, khác Min-Max. Giá trị âm nằm dưới trung bình, số 0 đúng tại trung bình, giá trị dương nằm trên trung bình.

## Code với Pandas

```python
import pandas as pd

s = pd.Series([2, 4, 6, 8, 10], dtype="float64")
z = (s - s.mean()) / s.std(ddof=0)
print(z.round(3))
```

Hãy để ý `ddof=0` ở đây: dùng độ lệch chuẩn theo tổng thể để minh họa công thức. `Series.std()` mặc định dùng `ddof=1`, nên kết quả có thể khác. Hai lựa chọn đều có ý nghĩa thống kê riêng.

## Code với Scikit-learn

```python
from sklearn.preprocessing import StandardScaler
from pandas import DataFrame

df = DataFrame({"length": [2, 4, 6, 8, 10]})
df["length_zscore"] = StandardScaler().fit_transform(df[["length"]])
```

## Tóm tắt

Z-score biểu diễn khoảng cách tới trung bình theo đơn vị độ lệch chuẩn.

## Điểm dễ nhầm

Z-score bằng 0 nghĩa là giá trị bằng trung bình; Z-score âm nghĩa là thấp hơn trung bình.
